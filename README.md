LaunchAtlas is a token launch radar that ranks 200 DeFi protocols with no token recorded in the sealed DefiLlama snapshot by implied launch value. Its offline dashboard supports sorting and filtering, and every ranked protocol has a concrete farm plan with time and cost estimates.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts --input ../token-radar-01-kit/token-radar-01-kit/input/snapshot.json
```
