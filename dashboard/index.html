How values are calculated

Launch Atlas estimates the hypothetical dollar value of a token if the protocol’s snapshot record stayed as it is. The snapshot captures TVL, which can move with asset prices and flows. It does not record launch schedules or campaign eligibility.

Implied value = TVL × seven-day momentum × tracking tenure

Coverage and token status

“Trading reference” means the snapshot contains a CoinGecko ID, symbol or market cap. Board records lack all three fields. Verify current token and campaign status with official documentation.
